# Parista — концепт редизайна

Адаптивный фронтенд-концепт интернет-магазина климатической техники.

## Запуск

```bash
pnpm install
pnpm dev
```

## Сборка

```bash
pnpm build
```

## Важные интеграции перед публикацией

- В форме добавлен UI штатной CAPTCHA Битрикс. В боевой шаблон нужно передать `captcha_sid`, вывести изображение через `/bitrix/tools/captcha.php?captcha_sid=...` и проверить `captcha_word` на сервере.
- Кнопки корзины и форма в этом концепте демонстрационные; их нужно связать с реальными обработчиками магазина/CRM.
